## [Zeya](https://github.com/Zebeyova/Zeya)

> 开发时长：2025年10月23日 - 2026年3月7日 | 共计时长：135日
>
> **技术栈**：`.NET9 · WPF · Sodium · SQLite · MVVM`

在9月份多的时候，总是感觉电脑缺少点我想要的功能，经过一周的方案对比，最终选择使用 WPF 开发一款开源的个人小工具，引入第三方库 Lunar 实现日历模块，并自主实现了日程、代办、提醒、闹钟、托盘、键盘按键统计，黑白主题功能

虽说我成功给自己写了这么一个小工具，也使用了一段时间，但是总是感觉不顺手，且那时网上有一些其他作者的开源项目也是很不错的，如 [Pyisland](https://github.com/Python-island/Python-island)，这个我还是比较推荐的，缺点嘛，就是内存占用有点高，不知道后来优化了没

> [!TIP]
> 在2026年9月时发现了一款新的工具，感觉还不错，叫做[DeskBox](https://deskbox.fun/)，比较符合我的使用习惯，缺点依旧是占用较高，但是相比于 Pyisland 已经好很多了
